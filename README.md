### 🎀 BlindAid — AI-powered assistive Android application

<a href="https://github.com/maryem1008/blindaid">
  <img src="https://img.shields.io/badge/♡_EXPLORE_PROJECT-DB7093?style=for-the-badge&logo=github&logoColor=white" alt="Explore BlindAid"/>
</a>

An assistive application designed to help visually impaired users understand their surroundings through camera-based object detection and spoken descriptions.

**What makes it special**
- 👁️ Camera-based object detection.
- 🔊 Spoken descriptions using text-to-speech.
- 📱 Android development with a focus on accessible interaction.
- 🧠 On-device AI inference as the target deployment approach.

`Android` `Kotlin / Java` `CameraX` `YOLOv8` `TensorFlow Lite` `Computer Vision`

### 🌸 Telecom Alarm Analytics — Network Operations Dashboard

<a href="https://github.com/maryem1008/telecom-alarm-analytics">
  <img src="https://img.shields.io/badge/♡_EXPLORE_PROJECT-DB7093?style=for-the-badge&logo=github&logoColor=white" alt="Explore Telecom Alarm Analytics"/>
</a>

A telecom network monitoring and analytics project built around simulated Ericsson OSS alarm data, refreshed continuously to demonstrate a live network operations workflow.

**What it can do**
- 📡 Monitor alarms and network health through an interactive dashboard.
- 📊 Process alarm data with PySpark and PostgreSQL.
- 🗺️ Visualize network elements and alarm severity geographically.
- 🚨 Identify unusual alarm activity and group related alarms into incidents.
- 🛠️ Demonstrate controlled remediation workflows, including approval, dispatch tickets, and audit trails.

`Python` `PySpark` `PostgreSQL` `Streamlit` `Altair` `PyDeck` `Network Analytics`
